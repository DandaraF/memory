description: Verify Project
---

Faça uma revisão completa da implementação atual sem adicionar novas funcionalidades.

Verificar
erros de TypeScript;
lint;
build de produção;
imports incorretos ou desnecessários;
código duplicado;
código morto;
problemas de responsividade;
problemas de acessibilidade;
problemas de estado ou efeitos React;
timers sem cleanup;
possíveis memory leaks;
dados sensíveis hardcoded;
uso incorreto de variáveis de ambiente;
dependências desnecessárias;
compatibilidade com deploy na Vercel.

Execute os comandos de validação disponíveis no projeto.

Se encontrar problemas, corrija-os.

Não implemente funcionalidades novas durante essa revisão.

Ao finalizar, informe apenas:

problemas encontrados;
correções realizadas;
resultado do TypeScript;
resultado do lint;
resultado do build;
resultado dos testes.
