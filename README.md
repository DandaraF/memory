# 🧠 Jogo da Memória

Jogo da Memória moderno desenvolvido com **Next.js 16**, **React 19**, **TypeScript** e **Tailwind CSS 4**.

## Funcionalidades

- 🎴 Animação 3D de virada de cartas com CSS
- 🎯 4 níveis de dificuldade (Fácil, Médio, Difícil, Expert)
- 🎨 4 temas de cartas (Espaço, Animais, Fantasia, Arcade)
- ⏱️ Cronômetro, contador de jogadas e sistema de combo
- 🔊 Efeitos sonoros via Web Audio API (sem dependências externas)
- 🏆 Recorde salvo no localStorage por dificuldade
- 💡 Sistema de dica com penalidade de pontos
- ♿ Acessibilidade completa via teclado

## Como Rodar Localmente

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) no navegador.

## Scripts Disponíveis

```bash
npm run dev    # Inicia o servidor de desenvolvimento
npm run build  # Gera o build de produção
npm run lint   # Verifica erros de lint
```

## Tecnologias

- [Next.js](https://nextjs.org) — Framework React com App Router
- [Tailwind CSS](https://tailwindcss.com) — Estilização utilitária
- [TypeScript](https://www.typescriptlang.org) — Tipagem estática
